# Machfile Tap

## How do I install these formulae?

`brew install machfile/tap/<formula>`

Or `brew tap machfile/tap` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "machfile/tap"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
